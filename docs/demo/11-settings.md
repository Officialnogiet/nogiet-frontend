# 11 · Settings

Open **Settings** from the desktop sidebar or the phone's **More** menu. This screen contains local display preferences and the alert controls available to your account.

- **Guided tour:** Select **Start guided tour** to replay the step-by-step walkthrough. The **?** button on any screen also offers quick tips and a tour shortcut.
- **Appearance:** Switch dark mode and select the emission unit used by dashboard figures, charts, and tables: kg/hr, kg/day, tonnes/year, or CO₂e/hr.
- **Notifications:** Toggle email or browser push notifications and set the default alert threshold. Browser push permission may be requested if you enable it.
- **Data & Privacy:** Choose local data retention and a preferred export format.
- **Map & Region:** Choose a starting region and a default map style.

Preferences in `useSettingsStore` are saved in this browser. Some notification values also call the backend. Browser-local choices do not automatically follow you to another device.

If a screen is unfamiliar, start the guided tour. Use **Next** and **Back** to move through it, **Skip tour** or Escape to close it, and return here whenever you want to restart.
